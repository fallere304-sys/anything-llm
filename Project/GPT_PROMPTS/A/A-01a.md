## Static safety rules — a pattern is UNSAFE if ANY of these holds
Length is measured in runes (`utf8.RuneCountInString`).
1. Length > 256.
2. Contains any of these substrings: `(?=`  `(?!`  `(?<=`  `(?<!`
3. Contains a backreference: a backslash followed by a digit `1`-`9` (e.g. `\1`), or the substring `\k<`, or the substring `(?P=`.
   - Be careful: `\\1` (an escaped backslash followed by the digit 1) is NOT a backreference. Scan left to right, treating `\` as an escape that consumes the next character.
4. A parenthesised group that is itself followed by an unbounded repetition, and whose body contains a quantifier or an alternation.
   Definitions for rule 4:
   - Scan the pattern left to right, character by character (runes).
   - A backslash escapes the next character (skip both); escaped characters are never special.
   - Inside a character class `[...]` nothing is special. A class starts at an unescaped `[`; if the next char is `^` skip it; if the next char is `]` it is a literal (skip it); the class ends at the next unescaped `]`.
   - Outside a class, an unescaped `(` opens a group. If it is immediately followed by `?`, it is a special group such as `(?:`, `(?i)`, `(?i:`, `(?P<name>` or `(?<name>`; skip the `?` and then skip characters up to and including the first `:` or `>` or `)`. (If the terminator was `)`, the group is already closed and has no body: treat it as an empty group with nothing recorded.)
   - Each open group has a boolean "dirty" flag, initially false.
   - Outside a class, the characters `*` and `+` and `?` are quantifiers, and `{` is a quantifier only if it matches the form `{n}`, `{n,}` or `{n,m}` (n, m digits) starting at that position (skip over the whole `{...}`). Seeing a quantifier or an unescaped `|` sets the dirty flag of the innermost open group (if any).
   - On an unescaped `)` that closes a group: pop it. Let `unbounded` be true if the next character is `*` or `+`, or if the next characters form `{n,}` or `{n,m}` (a comma inside the braces). (`?` and `{n}` do NOT count as unbounded.) If the popped group's dirty flag is true AND `unbounded` is true → UNSAFE. Otherwise, if the popped group was dirty, propagate dirty=true to the new innermost open group (if any).
   - Unbalanced parentheses must not panic: ignore a `)` with no open group; ignore groups still open at the end. (Compilation will report invalid syntax later.)
