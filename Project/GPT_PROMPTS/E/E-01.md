from typing import Optional

@dataclass(frozen=True)
class Expected:
    rule_id: str                 # e.g. "E001"
    record_no: int               # 1-based number of the DATA record (header excluded). 0 means the header row.
    column: Optional[str]        # column name, or None for record-level findings

    def to_json(self) -> dict:
        """Return {"rule_id":..., "record_no":..., "column":...} (column may be None)."""

    def sort_key(self) -> tuple:
        """Return (record_no, column or "", rule_id)."""

    expected: list[Expected] = field(default_factory=list)
    encoding: str = "utf-8"                       # one of "utf-8", "utf-8-sig", "cp932"
    newline: str = "\r\n"                         # one of "\r\n", "\n", "\r"
    trailing_newline: bool = True                 # whether the last record is followed by a newline
    delimiter: str = ","

    raw_override: Optional[bytes] = None          # if not None, these exact bytes are written as the CSV file (used for malformed files)
```

## `make_clean_rows` — generation rules (every generated row must be DEFECT-FREE under the rules above)
For row index `i` (0-based) produce 8 strings in header order:
1. 患者ID: `str(start_id + i)`; must be exactly 8 digits (raise `ValueError` if `start_id + n_rows - 1 > 99999999` or `start_id < 10000000`).
2. 氏名: `rng.choice(SURNAMES) + rng.choice(GIVEN_NAMES)`.
3. 生年月日: a random valid date between 1930-01-01 and 2010-12-31 inclusive, formatted `YYYY-MM-DD` (use `datetime.date.fromordinal` with `rng.randint` on ordinals).
4. 性別: `rng.choice(["男","女"])`.
5. 入院日: random valid date between 2020-01-01 and 2024-12-31 inclusive, `YYYY-MM-DD`.
6. 退院日: the 入院日 plus `rng.randint(0, 60)` days, `YYYY-MM-DD` (so 入院日 <= 退院日 always; it is never empty).
7. 点数: `str(rng.randint(0, 1000))` (plain digits, no sign, no leading zeros except "0" itself).
8. 備考: `rng.choice(NOTES)`.

```
- `"utf-8"` → UTF-8 without BOM; `"utf-8-sig"` → UTF-8 with BOM (`EF BB BF`); `"cp932"` → Python codec `cp932` with `errors="strict"`. Any other value → `ValueError`. An unencodable character raises `UnicodeEncodeError` (let it propagate).

```python
def split_for(case_id: str) -> str
```
- Compute `int(hashlib.sha256(case_id.encode("utf-8")).hexdigest()[:8], 16) % 10`; return `"dev"` if the value is < 3, else `"holdout"`.

```python
def write_case(case: CaseData, out_dir: str) -> dict
```
- Validate: `case_id` matches `^[A-Za-z0-9_-]+$` (else `ValueError`); `newline` and `encoding` are among the allowed values.
- Let `split = split_for(case.case_id)`; create `out_dir/<split>/` (`os.makedirs(..., exist_ok=True)`).
- Write three files into that directory:
  - `<case_id>.csv`: if `raw_override` is not None → write those bytes verbatim; else `encode_text(serialize_csv(...), case.encoding)`. Open with `"wb"`.
  - `<case_id>.rules.json`: `json.dumps(case.rules, ensure_ascii=False, indent=2, sort_keys=True) + "\n"`, UTF-8 without BOM, newline `"\n"` (write bytes).
  - `<case_id>.expected.json`: `json.dumps({"schema_version": 1, "case_id": case.case_id, "expected": [e.to_json() for e in sorted(set(case.expected), key=Expected.sort_key)]}, ensure_ascii=False, indent=2, sort_keys=True) + "\n"` (duplicates removed; UTF-8, no BOM).
- Return a manifest entry dict: `{"case_id", "split", "encoding", "tags": sorted(case.tags), "files": {"csv": "<split>/<case_id>.csv", "rules": "<split>/<case_id>.rules.json", "expected": "<split>/<case_id>.expected.json"}, "csv_sha256": "<hex of the csv bytes>", "record_count": len(case.rows), "expected_count": <number of distinct expected>}`.
