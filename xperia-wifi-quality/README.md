# Wi-Fi電波品質（Xperia Z4 向け）

周囲の Wi-Fi 電波をすべて一覧表示し、推定通信品質を算出する Android アプリ。

- 10 秒ごとに再スキャンして更新
- 検知したすべての電波（BSSID 単位）を表示し、電波の強い順（RSSI 降順）に並べる
- 各行の表示: SSID / ch（バンド・チャネル幅・BSSID）/ 電波強度の横棒グラフ（dBm）/ 推定通信品質 %
- 接続中の AP には ★ を表示
- 計測中は画面を消灯させない

APK: [`dist/WifiQuality.apk`](dist/WifiQuality.apk)（minSdk 21 = Android 5.0、targetSdk 23）

## インストール

1. APK を端末にコピーする
2. 「設定 → セキュリティ → 提供元不明のアプリ」を許可する
3. APK をタップしてインストールする
4. Android 6.0 以降では、初回起動時に位置情報の権限を「許可」し、位置情報（GPS）をオンにする。
   Android の仕様上、この 2 つがないとスキャン結果を取得できない。

## 推定通信品質の計算

`推定品質 = 信号係数 × 混線係数 × 100`（至近距離・混線なしのとき 100%）

**信号係数**: IEEE 802.11n/ac の受信最小感度（20MHz）で、その RSSI で使える MCS の
伝送レートを MCS9 (86.7Mbps) で割った値。区間は線形補間する。
チャネル幅が 2 倍になるごとに必要な感度は 3dB 上げる。

| RSSI (20MHz) | -57 | -59 | -64 | -66 | -70 | -74 | -77 | -79 | -82 | -90 |
|---|---|---|---|---|---|---|---|---|---|---|
| 信号係数 | 100% | 90% | 75% | 60% | 45% | 30% | 22.5% | 15% | 7.5% | 0% |

**混線係数**: 同じバンドで周波数が重なる他の電波ごとに次の値を足し合わせ、その合計を「負荷」とする。
- 重なり率: 自分のプライマリ ch への重なりと、チャネル全体への重なりの大きい方。2.4GHz は 22MHz 幅として扱う
- 強度係数: -90dBm で 0、-62dBm 以上で 1（間は線形）

`混線係数 = 1 / (1 + 0.5 × 負荷)` とする。係数 0.5 は、他の電波が平均して半分の時間送信していると仮定した値。
同じ ch に強い電波が 1 つあると 67%、3 つあると 40% になる。

画面には、混線の度合い（混線なし / 小 / 中 / 大）、同じ ch の電波数、部分的に重なる電波数、信号係数、混線係数も表示する。

> 注意: 推定値はスキャンで得た情報（RSSI・周波数・チャネル幅）だけから計算している。
> 実際のトラフィック量・端末性能・MIMO の本数・壁の反射などは反映されない。
> Android 5.x ではチャネル幅を取得できないため、すべて 20MHz として計算する（画面には「幅不明」と表示）。

## ビルド

Gradle は使わず、Ubuntu の Android SDK パッケージでビルドする。

```sh
sudo apt-get install aapt apksigner zipalign android-sdk-platform-23 dalvik-exchange
./build.sh                                        # → dist/WifiQuality.apk
java -cp <classes> QualityEstimatorTest          # 推定ロジックのテスト（test/）
```

署名鍵は初回ビルド時に `keystore/` へ自動生成する（git には含めない）。
別の鍵でビルドした APK を上書きインストールすることはできないので、その場合は一度アンインストールしてから入れ直す。
