# Z4 MotionCam ビューア（Google スプレッドシート / Apps Script 版）

複数台の Z4 MotionCam を、**Google 経由で**1つの画面から見るためのビューアです。

- 閲覧端末が通信するのは Google（script.google.com）だけです。カメラへの接続は Google のサーバーが代わりに行うので、セキュリティソフトがカメラへの直接接続を止める環境でも使えます。
- 画面上部のドロップダウンでカメラを切り替えます（ブラウザのタブ切り替えは不要）。
- ライブ映像、録画の再生・保存・削除（一括も可）、監視のオン・オフができます。
- 画面下部のフォームで、IP・ポート・パスワードを入力してカメラを登録します。

## しくみと制約

```
閲覧端末 ──(Google とだけ通信)── Google Apps Script ──(HTTPS)── 各カメラ（Z4）
```

| 項目 | 内容 |
| --- | --- |
| ライブ映像 | Google が約 1 秒ごとに静止画を取ってきて表示します（動画のような滑らかさはありません）。通信回数を節約するため 3 分で自動停止します |
| 録画の再生・保存 | 8MB ずつ取得し、全部そろってから再生・保存します（MP4 は途中から再生できないため）。5 分（約 37MB）の録画で数十秒が目安です。**Z4 の「1ファイルの最大長」は 5〜10 分をおすすめします**（「区切らない」で長くなったファイルは時間がかかります） |
| 一括保存 | 1 件ずつ順番に保存します（ZIP にまとめると Google の 50MB 制限を超えるため）。ブラウザが「複数ファイルのダウンロード」の許可を求めることがあります |
| 回数の上限 | Google がカメラに接続できる回数には 1 日の上限があります（個人の Google アカウントで 1 日 2 万回程度とされていますが、Google の方針で変わることがあります）。ライブ映像 1 分で約 60 回、状態の更新は 20 秒に 1 回です |
| カメラ側の条件 | 各カメラで「外出先からの視聴」を有効にし、ルーターでポートマッピングが必要です（Google は家の外から接続するため）。2 台目以降は別のポート番号にします（v6プラス / OCN バーチャルコネクトでは「利用可能ポート」の範囲から選ぶ） |

## 設置手順

1. Google ドライブで**新しいスプレッドシート**を作ります（名前は例えば「Z4 MotionCam」）。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. エディタで次の 3 つを用意します。
   - `コード.gs`（最初からあるファイル）の中身を全部消し、このフォルダの **`Code.gs`** の内容を貼り付けます。
   - 左の「ファイル」の **＋ → HTML** で `Index` という名前のファイルを作り、**`Index.html`** の内容を貼り付けます（名前は `Index` のみ。`.html` は自動で付きます）。
   - 左の歯車（プロジェクトの設定）で「"appsscript.json" マニフェスト ファイルをエディタで表示する」をオンにし、`appsscript.json` の内容を **`appsscript.json`** で置き換えます。
4. 保存（Ctrl+S / ⌘+S）します。
5. 右上の **デプロイ → 新しいデプロイ** を開き、種類で「ウェブアプリ」を選びます。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **自分のみ**
6. 「デプロイ」を押すと、Google アカウントへのアクセス許可を求められます。
   「このアプリは Google で確認されていません」と出た場合は、「詳細 → （プロジェクト名）に移動」で進み、許可します（自分で作ったスクリプトなので問題ありません）。
7. 表示された **ウェブアプリの URL** をスマホで開きます。ホーム画面に追加しておくと便利です。
8. 画面下部の「カメラの登録」に、カメラごとに次を入力して登録します。
   - 名前（例: 寝室）
   - IP / アドレス（例: 203.0.113.5）
   - ポート（そのカメラの外出先用ポート。例: 5880）
   - パスワード（そのカメラの外出先視聴用パスワード）

   登録時に実際に接続して確かめます。

スプレッドシートを開いたときに出るメニュー **「Z4 MotionCam → ビューアを開く」** からも、同じ画面をスプレッドシートの上に表示できます。

## 家族など複数の Google アカウントで使う場合

手順 5 を次のようにします。

- 次のユーザーとして実行: **ウェブアプリにアクセスしているユーザー**
- アクセスできるユーザー: **Google アカウントを持つ全員**

そのうえで、次の 2 つを行います。

1. プロジェクトの設定 → スクリプト プロパティに、`ALLOWED_EMAILS` という名前で、使ってよい人のメールアドレスをカンマ区切りで登録します（例: `me@gmail.com,family@gmail.com`）。ここにない人は URL を知っていても使えません。
2. スプレッドシートを、その人たちと**編集者**として共有します（カメラ一覧の読み書きに必要）。

## 安全について

- パスワードはシートには書かず、スクリプト プロパティ（画面に出ない保存場所）に保存します。シートにはカメラの名前・アドレス・ポートだけが残ります。
- Google からカメラへの通信は HTTPS（暗号化）です。カメラの証明書は Z4 が自分で作ったものなので、証明書の発行元の確認は行っていません。
- 「自分のみ」で公開すれば、ほかの人はウェブアプリの URL を知っていても開けません。

## 更新するとき

`Code.gs` / `Index.html` を貼り替えて保存したあと、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン → デプロイ** を行います。URL は変わりません。
