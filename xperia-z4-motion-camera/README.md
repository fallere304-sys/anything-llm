# Z4 MotionCam

Xperia Z4 を常時充電のまま使う、低発熱の見守りカメラアプリです。
動体を検知したときだけ録画し、同じ Wi-Fi にいるスマホや PC のブラウザから、ライブ映像と録画を見られます。

- 対象: Xperia Z4 (SO-03G / SOV31 / 402SO)。Android 5.0〜7.0 (minSdk 21 / targetSdk 25)
- 依存ライブラリなし（Android フレームワークの API だけを使用）。見る側はブラウザだけでよく、専用アプリは不要

## 要件と実装の対応

| 要件 | 実装 |
| --- | --- |
| 動体検知で録画 | プレビューの輝度を 32×24 マスに縮めて背景と比較し、2回続けて変化したら録画を開始します。動きが止まって N 秒たつと録画を止めます（`MotionDetector`, `CameraPipeline`） |
| LAN からライブ映像・録画を見る | 自前の小さな HTTP サーバーです。ライブは MJPEG、録画は Range 対応の MP4 配信で、シーク再生もできます（`HttpServer`, `assets/index.html`） |
| 外出先からの視聴 | ルーターのグローバル IP 宛てに HTTPS で公開します。ルーターのポート開放（UPnP）と、任意で DDNS 更新も自動で行います（`RemoteAccess`） |
| 録画データの管理 | 1 件ずつ保存・削除できるほか、チェックボックスで選んだ録画をまとめて保存（ZIP）・削除できます |
| 充電中でも熱暴走しない | 下の「発熱対策」を参照 |
| 30 秒でバックライト OFF | 最後のタッチから 30 秒で、輝度を最低にして黒一色の画面にします。画面の更新も止めます（`MainActivity`） |
| タッチでバックライト ON | 暗い間は、どこをタッチしても元の輝度に戻ります。復帰したときのタッチでボタンが押されることはありません |
| 稼働記録 | 起動時刻と稼働時間を記録します。1 分ごとに「動作中」の記録を書くので、突然電源が切れても、最後の記録時刻（誤差 1 分以内）と直前の電池の状態が残ります（`UptimeLog`） |
| 容量がいっぱいなら古い録画を削除 | 録画を始めるときと、録画中は 15 秒ごとに空き容量を確認します。設定値を下回ったら古いファイルから削除します（`RecordingStore`） |

## 発熱対策

既存の見守りカメラが熱暴走した原因は、常時フル稼働で処理していることだと考えています。
Z4 の SoC である Snapdragon 810 は発熱しやすいことで知られています。
そこで、必要なときだけ必要なぶんだけ処理するように作りました。

1. **カメラは低解像度・低フレームレート**: 標準は 640×480・10fps です。設定値に届く中で最も遅いフレームレート範囲を選び、下限も低いものを選ぶので、暗い部屋でも無理に高感度にしません。
2. **待機中はカメラ自体を遅く動かす**: 録画しておらず誰も見ていない間は、センサーを 5fps 前後で動かします（動体検知には十分）。動きを検知したりライブを開いたりすると、設定のフレームレートに上がります。電池温度が 42℃ を超えたら、録画中も遅いままにします。
3. **エンコードは録画中だけ**: 監視中は動体検知しか動かしません。録画中だけハードウェアの H.264 エンコーダ（MediaCodec）を使い、ソフトウェアエンコードはしません。
4. **動体検知はとても軽い**: どの解像度でも 1 フレームあたり約 2 万画素を読むだけです（解像度が高いほど間引きます）。これを 1 秒に 3 回まで行います。
5. **JPEG は見ている人がいるときだけ作る**: ライブ映像を見ている人がいなければ、JPEG 圧縮は一切しません。1280 幅以上ではライブ映像を縦横半分にしてから圧縮します（録画は元の解像度のまま）。ブラウザのタブを隠すとライブは自動で止まります。見っぱなしでも 10 分で止まり、「ライブ再開」ボタンで続きを見られます。
6. **画面の描画を止める**: 暗い間はプレビューも文字も更新しません。明るい 30 秒間だけ 0.5 秒ごとに更新します。
7. **外部との通信は最小限**: IP 確認サービスなどには一切接続しません。外出先視聴を有効にしたときだけ、30 分に 1 回ルーターのポート開放を更新します（DuckDNS を設定した場合はその更新も）。
8. **電池温度で段階的に負荷を下げる**（`ThermalPolicy`。戻るときは 2℃ のヒステリシスあり）:

   | 電池温度 | 動体検知 | ライブ | 録画 fps |
   | --- | --- | --- | --- |
   | 39℃ 未満 | 3 回/秒 | 5 fps | 設定値 |
   | 39℃ 以上 | 2 回/秒 | 2 fps | 最大 8 |
   | 42℃ 以上 | 1 回/秒 | 1 fps | 最大 5 |
   | 45℃ 以上 | **カメラを一旦解放して冷却を待ちます**（43℃ を下回ると自動で再開。録画中のファイルは正しく閉じます） |

   45℃ で止める理由: 端末が熱で強制終了すると、その後は何も記録できません。短時間止めて冷ますほうが、失う時間が少なく済みます。

9. **再起動からの復帰**: 端末が起動すると自動で監視を再開します（設定でオフにできます）。

### 端末側でやっておくと効果が大きいこと

- **急速充電器（Quick Charge）を使わない**: 5V/1A 程度の普通の充電器にします。充電による発熱が大きく減ると考えられます。
- **いたわり充電（Battery Care）をオンにする**: Android 6 以降の Xperia にある機能です。満充電のまま充電し続ける時間を減らせます。
- ケースを外し、放熱しやすい向き（背面を浮かせる）で設置します。直射日光と布団の上は避けてください。
- 画面ロックを「なし」にします。停電などで再起動したとき、ロック解除なしで監視を再開するためです。
- 自動アップデートと不要なアプリを止め、裏で動く処理を減らします。

## ダウンロード（ビルド済み APK）

Z4 のブラウザで次の URL を開くとダウンロードできます。

https://github.com/fallere304-sys/anything-llm/raw/claude/xperia-z4-motion-camera-7x4wet/xperia-z4-motion-camera/release/z4motioncam-1.4.apk

1. 「設定 > セキュリティ > 提供元不明のアプリ」をオンにします。
2. ダウンロードした APK を開いてインストールします。

注意: このAPKは開発環境で作った署名鍵で署名しています。**別の鍵で署名されたAPKでは上書き更新できません。** その場合は一度アンインストールが必要で、アンインストールすると保存済みの録画（`Android/data/com.z4motioncam/`）も消えます。更新するときは先に録画を退避してください。

## ビルドとインストール

Android Studio（JDK 17 以上）でこのフォルダ `xperia-z4-motion-camera/` を開き、そのままビルドします。

```sh
cd xperia-z4-motion-camera
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`./gradlew test` で PC 上の単体テストを実行できます。対象は動体検知、温度制御、ストレージ削除、HTTP（Range・削除・ZIP・認証）、HTTPS、UPnP、色変換・縮小です。

Z4 に入れるには、「設定 > セキュリティ > 提供元不明のアプリ」を許可してから APK を入れてください。

Android Studio を使わずに作る場合は、Ubuntu のパッケージ（`aapt` `apksigner` `zipalign` `dalvik-exchange` `android-sdk-platform-23`）を入れて `./build-apk.sh` を実行します。`release/` に署名済み APK ができます。

## 使い方

1. アプリを起動し、カメラの権限を許可します。
2. 画面左上に `http://192.168.x.x:8080/` が出るので、同じ Wi-Fi のスマホや PC のブラウザで開きます。
   - 上がライブ映像、下が録画一覧です。日時をタップすると再生します。
   - 各録画の右にある「保存」でダウンロード、「削除」で削除します（確認あり）。
   - 左のチェックボックスで録画を選び、一覧の上にある「一括保存」「一括削除」を押すと、選んだ録画だけをまとめて処理します。「すべて選択」で全件を選べます。
   - 一括保存は、1 件なら MP4 のまま、2 件以上なら 1 つの ZIP（無圧縮で、スマホ側の負荷はほとんどありません）で保存します。ZIP は合計 3.9GB までです（Android 7 未満は 4GB を超える ZIP を作れないため）。
   - 録画中のファイルは一覧に出ないので、削除されることはありません。
   - 状態、電池温度、空き容量、最後に動きを検知した時刻も表示されます。
3. 30 秒たつと画面が暗くなります。タッチすると 30 秒間だけ元に戻ります。
4. 「停止」ボタンで監視を終了します。

### 設定（画面の「設定」ボタン）

| 項目 | 標準値 | 説明 |
| --- | --- | --- |
| 解像度 | 640×480 | 320×240 / 640×480 / 960×720 / 1280×720 / 1280×960 / 1920×1080。大きいほど発熱が増えます。1920×1080 は非推奨・実機未検証です |
| フレームレート（録画） | 10 fps | 1 / 2 / 3 / 5 / 7 / 10 / 15 / 20 / 24 / 30。低いほど発熱が減ります。20 以上は非推奨です |
| 映像の回転 | 0° | 設置の向きに合わせます（録画とライブの両方に反映） |
| 検知感度 | 中 | 「高」は寝返りのような小さな動き向け。誤検知が多ければ「低」にします |
| 録画を続ける秒数 | 10 秒 | 動きが止まってから録画を止めるまでの時間 |
| 1 ファイルの最大長 | 5 分 | 動きが続くときは、この長さでファイルを分けます |
| SD カードを優先 | オン | microSD があればそこに保存します |
| 確保する空き容量 | 500 MB | これを下回ると、古い録画から削除します |
| ポート番号 | 8080 | 家の中（LAN）用。パスワードは不要です |
| 外出先からの視聴を有効にする | オフ | 下の「外出先からの視聴」を参照 |
| 外出先視聴用パスワード | （なし） | 8 文字以上。外出先（HTTPS）からだけ求められます（ユーザー名は何でも可） |
| 外部アドレス（グローバル IP） | （なし） | 外出先 URL に使います。空欄ならルーターが報告する IP を使います |
| 外出先用ポート番号 | 8443 | HTTPS 用。LAN 用ポートと別の番号にします |
| ルーターのポートを自動で開放（UPnP） | オン | オフのときはルーターで手動の転送設定が必要です |
| DuckDNS ドメイン名 / トークン | （なし） | 任意。IP が変わっても同じ URL で接続できます |
| 起動時に自動で開始 | オン | |

録画は `Android/data/com.z4motioncam/files/Movies/recordings/`（SD カードまたは内部ストレージ）に `yyyyMMdd_HHmmss.mp4` という名前で保存されます。

## 稼働記録（突然の電源断の調査）

ブラウザの「稼働記録」欄で、次のことが分かります。

- **現在の稼働時間**と開始時刻
- **過去の稼働**: 開始 → 終了（最後に動作を確認した時刻）、稼働時間、終わり方、直前の電池の状態
- **電池の記録**: 5 分ごとの電池残量・温度・電圧・充電状態・負荷制御レベル（直近 24 時間を表示。7 日分を保存）

アプリは 1 分ごとに「動作中」をストレージへ書き込みます（記録内容は電池と負荷の状態だけで、発熱への影響はありません）。
次に起動したとき、前回の記録が閉じられていなければ「突然止まった」と判断し、最後の書き込み時刻を終了時刻として残します。

| 終わり方 | 判定の仕方 |
| --- | --- |
| 停止ボタン（アプリ停止） | 停止したときに記録 |
| 端末のシャットダウン・再起動 | OS のシャットダウン通知を受けて記録（電源メニュー、OS による電池切れ・過熱の停止を含む） |
| **突然の電源断**（通知なし） | 次の起動時、端末の起動からの経過時間がリセットされていることで判定 |
| アプリだけが強制終了 | 次の起動時、起動からの経過時間が続いていることで判定 |

「直前の状態」の見方の例:

- 充電が「接続中・充電停止」で、温度が高く、電池残量が少ない → 熱で充電が止まり、電池切れで落ちた
- 温度が高く、電池残量が多い → 本体の過熱で落ちた
- 温度も残量も問題ない → 電池の劣化や本体の異常

## 外出先からの視聴

ルーターにグローバル IPv4 が割り当てられている環境で使えます（ルーターの WAN 側 IP と、https://api.ipify.org に表示される IP が同じなら該当します）。

### 有効にする

1. Z4 の「設定 > 外出先からの視聴」で、**外出先視聴用パスワードを 8 文字以上**にします。
2. 「外出先からの視聴を有効にする」をオンにします。
3. 「外部アドレス」にグローバル IP を入れます。空欄のままでも、ルーターが UPnP で報告する IP を使います。
4. 任意で DuckDNS を設定します。https://www.duckdns.org で無料のサブドメインを作り、ドメイン名とトークンを入力します。グローバル IP が変わっても、同じ URL で接続できるようになります。
5. Z4 の画面と、LAN のブラウザの「外出先からの視聴」欄に、外出先用の URL と証明書の指紋が出ます。

UPnP が使えないルーターでは、ルーターの管理画面で TCP 8443 番を Z4 の LAN IP の 8443 番へ転送してください。

ルーターが報告する IP が「外部アドレス」と違ってきた場合（IP が変わった場合）は、Z4 の画面とブラウザに警告が出ます。

### 外出先から開く

スマホの**モバイル回線**（Wi-Fi をオフ）で外出先 URL（例: `https://グローバルIP:8443/`）を開きます。

証明書は Z4 が自分で作ったもの（自己署名）なので、初回はブラウザに「保護されていない通信」と警告が出ます。
「詳細」で表示される SHA-256 の指紋が、Z4 に表示された指紋と一致することを確かめてから進んでください。
一致しない場合は、途中で通信を横取りされている恐れがあるので、接続しないでください。

### 安全対策

- 外出先用ポートは **HTTPS（TLS 1.2 以上）だけ**で、**パスワードがないと何も返しません**。
- パスワードを 5 回間違えると、その IP からの接続を 15 分間ブロックします。
- LAN 用の HTTP ポート（8080）はパスワードなしで使えます。その代わり、家の中（プライベートアドレス）以外からの接続は拒否します。
- ルーターで開けるのは外出先用ポートだけです。外出先視聴を無効にするか、アプリを停止すると閉じます。
- 自宅のグローバル IP は、公開リポジトリのソースコードには含めていません（個人用ビルドでだけ `EXTERNAL_HOST` で埋め込めます。下記）。

### 個人用ビルド（外部アドレスを埋め込む）

```sh
EXTERNAL_HOST=203.0.113.5 APK_NAME=/安全な場所/z4motioncam-home.apk ./build-apk.sh
```

「外部アドレス」の初期値が入った APK ができます。**自宅 IP を含むので、公開リポジトリには置かないでください。**

## 構成

```
MainActivity     画面（プレビューと状態表示、30 秒で減光、タッチで復帰）
CameraService    フォアグラウンドサービス（カメラ、HTTP、電池温度の監視、WakeLock）
 ├─ CameraPipeline   Camera1 のプレビューコールバックを受け、1 本のスレッドで検知・録画・JPEG 生成
 │   ├─ MotionDetector   輝度グリッドの背景差分（中央値で明るさ補正、2 回連続で確定）
 │   ├─ VideoRecorder    NV21 → NV12/I420 変換 → MediaCodec (H.264) → MediaMuxer (MP4)
 │   └─ PreviewSink      画面に出さない 1×1 の EGL サーフェス（プレビューの受け皿）
 ├─ RecordingStore   保存先、空き容量の確保、古い録画の削除
 ├─ FrameHub         最新の JPEG を見る人に渡す（見る人がいるときだけ生成）
 ├─ UptimeLog        稼働記録（1 分ごとのハートビート、5 分ごとの電池記録、終わり方の判定）
 ├─ RemoteAccess     HTTPS サーバー（自己署名証明書 TlsIdentity）、UPnP ポート開放（Upnp）、DuckDNS 更新
 ├─ HttpServer       / , /stream.mjpg , /snapshot.jpg , /api/status , /api/recordings , /rec/<name>
 │                   /api/uptime（稼働記録）, POST /api/delete（削除）, POST /api/zip（一括保存）
 └─ ThermalPolicy    電池温度 → 負荷レベル
```

## 制約・注意点

- **バックライトを完全に消すことはできない**: 公開 API では、タッチを受け付けたままパネルの電源を切れません。輝度 0 を指定しても、Android 側で「その機種の最低輝度」に切り上げられます。黒一色の表示と組み合わせるので、見た目はほぼ真っ暗になります。発熱への影響はごく小さいと見ています。
- **音声は録音しません**（要件外）。泣き声で通知したい場合は、音声を扱う機能を別途追加する必要があります。
- **録画開始の遅れ**: 動きを見つけてから録画が始まるまで、0.5〜1 秒ほどかかります（事前録画はしていません。処理を増やさないためです）。
- **赤外線はありません**: 真っ暗な部屋では写りません。常夜灯などの弱い明かりが必要です。
- **LAN 内の通信は暗号化されておらず、パスワードもない**: LAN 用の 8080 番は HTTP で、家の Wi-Fi につながる人は誰でも視聴・削除できます（家の外からは接続できません）。ルーターで 8080 番を手動で開放しないでください。
- **フレームレートの切り替え**: 待機中と録画中でセンサーの速度を切り替えます。切り替えに対応しないカメラドライバーの場合は、自動で固定速度に戻ります。
- **自己署名証明書**: 外出先で開くと、ブラウザの警告が出ます。これを避けるには独自ドメインと正規の証明書が必要ですが、処理を増やさないために対応していません。
- **外出先での視聴は通信量がかかる**: ライブ映像は 1 分あたり約 10MB（640×480・5fps の場合）です。
- **実機では未確認**: この実装は、Android 5.0 と 7.1 の API に対してコンパイルできることと、PC 上の単体テストで確認しただけです。温度の閾値は一般的なリチウムイオン電池の目安から決めたので、実機で様子を見て `ThermalPolicy` の値を調整してください。
